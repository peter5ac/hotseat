# Heads-Up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Heads Up-style guessing game where a player holds the phone to their forehead in landscape and tilts up=correct / down=pass through a 90-second round, then sees a recap.

**Architecture:** Follows the established per-game pattern: a SwiftUI `View` + `@Observable` view model, a `CADisplayLink` tick driver (copied from TugOfWar), and routing through `AppScreen`/`AppViewModel`. One new dependency — `CMMotionManager`, wrapped in a standalone `@Observable MotionTracker` that publishes a signed `pitch` and `isLandscape` so the view model stays free of CoreMotion and remains pure.

**Tech Stack:** SwiftUI, iOS 17+, Swift 5, CoreMotion (`CMMotionManager`), CoreHaptics/UIKit haptics, CADisplayLink.

## Global Constraints

- iOS 17+, Swift 5, SwiftUI, universal (iPhone + iPad). (from CLAUDE.md)
- No network, no accounts, no analytics, no persistence — per-session only. (from PRODUCT.md guardrails)
- Display name "Hot Seat", bundle id `com.audrey.HotSeat`. (from CLAUDE.md)
- Camera preview is black in the simulator; motion is unavailable in the simulator — primary validation is on a physical device. (from CLAUDE.md + spec)
- Xcode project uses hand-assigned object IDs. Next free build-file ID: `A1000014`; next free file-ref ID: `A2000014`. New files must be registered in `project.pbxproj` in four places: PBXBuildFile, PBXFileReference, the `HotSeat` PBXGroup, and the `Sources` PBXSourcesBuildPhase. (from project.pbxproj inspection)
- No test target exists. Validation = `xcodebuild`/XcodeBuildMCP build succeeds + manual on-device test. View-model logic is written pure so a test target *could* be added later, but this plan does not add one. (from project inspection)
- Display name for the game tile/screens: "Heads Up". Internal id: `headsUp`. (from spec)
- Each category list ≥30 items EXCEPT Family Members (27, by design — do NOT pad). (from spec)
- Correct = tilt **up**, Pass = tilt **down**. (from spec)
- Require landscape; prompt "Turn sideways" in portrait. Timer keeps running on accidental mid-game portrait rotation. (from spec)
- Feedback: haptics (distinct correct vs pass) + full-screen green "CORRECT" / amber "PASS" flash + final-seconds cue under ~10s. No per-correct room audio. (from spec)

## File Structure

- `HotSeat/HeadsUpCategories.swift` (new) — `HeadsUpCategory` struct + `headsUpCategories` array (34 categories).
- `HotSeat/MotionTracker.swift` (new) — `@Observable` CoreMotion wrapper publishing `pitch` and `isLandscape`.
- `HotSeat/HeadsUpViewModel.swift` (new) — `@Observable` state machine, timer, deck, neutral-reset locking, guessed/missed lists. No CoreMotion import.
- `HotSeat/HeadsUpView.swift` (new) — SwiftUI view: picker, readying, countdown, play HUD, flash overlays, recap. Owns the display-link modifier.
- `HotSeat/ContentView.swift` (modify) — add `case headsUp` to `AppScreen`, `openHeadsUp()` to `AppViewModel`, and a `case .headsUp` in the screen switch.
- `HotSeat/HomeView.swift` (modify) — add a tile to `allGames` + a spin-wheel `case "headsUp"` + an `onSelectHeadsUp` callback.
- `HotSeat.xcodeproj/project.pbxproj` (modify) — register the 4 new source files.

## Task 2: MotionTracker (CoreMotion wrapper)

**Files:**
- Create: `HotSeat/MotionTracker.swift`

**Interfaces:**
- Produces:
  - `@Observable final class MotionTracker` with:
    - `var pitch: Double` — signed tilt in degrees. ~0 when held vertical at forehead level (landscape). Positive = tilted screen-back / top-edge-up; negative = tilted screen-forward / top-edge-down. (Exact sign is tuned on-device; the view model treats it relative to a captured neutral, so absolute sign only needs to be *consistent*.)
    - `var isLandscape: Bool` — true when the device's long axis is horizontal.
    - `var isAvailable: Bool` — false in the simulator / when device motion is unsupported.
    - `func start()` / `func stop()` — begin/end motion updates.

**Context for the implementer:** `CMMotionManager` must be a single long-lived instance (creating several drops updates). We push updates to the main queue and read `deviceMotion.gravity`, a unit-ish vector pointing "down" in device coordinates. In landscape the device's X axis is vertical-ish, so we derive pitch from `gravity.x` and `gravity.z`. `isLandscape` comes from comparing `abs(gravity.x)` (long axis) vs `abs(gravity.y)` (short axis).

- [ ] **Step 1: Create the file**

Create `HotSeat/MotionTracker.swift`:

```swift
import CoreMotion
import Foundation

/// Wraps CMMotionManager to publish a landscape-oriented pitch angle and a
/// coarse landscape flag. Kept separate from the game view model so the model
/// stays free of CoreMotion and testable with plain numbers.
@Observable
final class MotionTracker {
    /// Signed tilt in degrees. Near 0 when the phone is held vertically at
    /// forehead level in landscape. Sign distinguishes tilt-up from tilt-down;
    /// the absolute sign is only required to be *consistent* because consumers
    /// compare against a captured neutral.
    var pitch: Double = 0

    /// True when the device's long axis is roughly horizontal (landscape).
    var isLandscape: Bool = false

    /// False on the simulator or any device without device-motion support.
    var isAvailable: Bool = false

    private let manager = CMMotionManager()

    init() {
        isAvailable = manager.isDeviceMotionAvailable
    }

    func start() {
        guard manager.isDeviceMotionAvailable else {
            isAvailable = false
            return
        }
        isAvailable = true
        manager.deviceMotionUpdateInterval = 1.0 / 60.0
        manager.startDeviceMotionUpdates(to: .main) { [weak self] motion, _ in
            guard let self, let motion else { return }
            let g = motion.gravity   // unit vector pointing "down" in device space

            // Landscape when the long axis (x) carries more gravity than the
            // short axis (y).
            self.isLandscape = abs(g.x) > abs(g.y)

            // Pitch from the long axis vs the screen-normal axis. atan2 keeps it
            // continuous and avoids gimbal flips near vertical. Result in degrees.
            let radians = atan2(g.z, g.x)
            self.pitch = radians * 180.0 / .pi
        }
    }

    func stop() {
        manager.stopDeviceMotionUpdates()
    }

    deinit {
        manager.stopDeviceMotionUpdates()
    }
}
```

**Files:**

**Interfaces:**

- Produces:
  - `enum HeadsUpState { case categoryPicker, readying, countdown, playing, recap }`
  - `enum FlashKind { case none, correct, pass }`
  - `@Observable final class HeadsUpViewModel` with:
    - `var state: HeadsUpState`
    - `var currentCategory: HeadsUpCategory?`
    - `var currentItem: String?`
    - `var guessed: [String]`, `var missed: [String]`
    - `var timeRemaining: Double` (seconds, starts at 90)
    - `var countdownValue: Int` (3→1)
    - `var flash: FlashKind`
    - `var isFinalSeconds: Bool` (timeRemaining <= 10 while playing)
    - `func selectCategory(_:)`, `func beginCountdown()`, `func tickCountdown(delta:)`, `func startPlaying()`, `func tickPlaying(delta:)`, `func registerPitch(_:neutral:)`, `func playAgain()`, `func backToPicker()`
    - constants exposed for the view: `static let roundDuration: Double = 90`

**Design notes for the implementer:**
- The deck is `currentCategory.items.shuffled()`. `deckIndex` walks it; no repeats. When `deckIndex` passes the end, the round ends early (recap).
- Neutral-reset locking: a boolean `awaitingNeutral`. When a tilt past the trigger threshold fires correct/pass, set `awaitingNeutral = true` and advance the deck *after* the pitch returns inside the neutral band. While `awaitingNeutral`, no new correct/pass can fire. This is what stops one tilt burning multiple items.
- Thresholds (relative to the captured neutral, in degrees, tuned on-device): `triggerDelta = 35`, `neutralBand = 15`. `triggerDelta > neutralBand` gives hysteresis.
- `registerPitch(_:neutral:)` is the pure entry point the view calls every frame with the live pitch and the neutral captured at countdown end. The view model never imports CoreMotion.
- Flash is set on the model; the view observes it and clears it on a timer (the model also clears it at the start of the next `registerPitch` transition so it never sticks).

Create `HotSeat/HeadsUpViewModel.swift`:

```swift
import Foundation

enum HeadsUpState {
    case categoryPicker
    case readying
    case countdown
    case playing
    case recap
}

enum FlashKind {
    case none
    case correct
    case pass
}

@Observable
final class HeadsUpViewModel {
    static let roundDuration: Double = 90

    // Thresholds in degrees, relative to the captured neutral. Tuned on-device.
    private let triggerDelta: Double = 35
    private let neutralBand: Double = 15

    var state: HeadsUpState = .categoryPicker
    var currentCategory: HeadsUpCategory?
    var currentItem: String?
    var guessed: [String] = []
    var missed: [String] = []
    var timeRemaining: Double = roundDuration
    var countdownValue: Int = 3
    var flash: FlashKind = .none

    var isFinalSeconds: Bool {
        state == .playing && timeRemaining <= 10
    }

    var totalGuessed: Int { guessed.count }

    private var deck: [String] = []
    private var deckIndex: Int = 0
    private var awaitingNeutral: Bool = false
    private var countdownAccumulator: Double = 0

    // MARK: Picker

    func selectCategory(_ category: HeadsUpCategory) {
        currentCategory = category
        state = .readying
    }

    func backToPicker() {
        state = .categoryPicker
        currentCategory = nil
        resetRoundState()
    }

    // MARK: Readying → countdown

    /// Called by the view once the phone has been held in the neutral band in
    /// landscape for the required dwell time.
    func beginCountdown() {
        guard state == .readying else { return }
        countdownValue = 3
        countdownAccumulator = 0
        state = .countdown
    }

    /// Advance the 3-2-1 countdown. Returns nothing; transitions to playing at 0.
    func tickCountdown(delta: Double) {
        guard state == .countdown else { return }
        countdownAccumulator += delta
        if countdownAccumulator >= 1.0 {
            countdownAccumulator -= 1.0
            countdownValue -= 1
            if countdownValue <= 0 {
                startPlaying()
            }
        }
    }

    // MARK: Playing

    func startPlaying() {
        guard let category = currentCategory else { return }
        deck = category.items.shuffled()
        deckIndex = 0
        guessed = []
        missed = []
        timeRemaining = Self.roundDuration
        awaitingNeutral = false
        flash = .none
        currentItem = deck.first
        state = .playing
    }

    /// Advance the round clock. Ends the round at 0.
    func tickPlaying(delta: Double) {
        guard state == .playing else { return }
        timeRemaining = max(0, timeRemaining - delta)
        if timeRemaining <= 0 {
            endRound()
        }
    }

    /// Pure motion entry point. `pitch` and `neutral` are degrees; `neutral` is
    /// the pitch captured when the countdown finished. Marks correct (tilt up)
    /// or pass (tilt down) with neutral-reset locking.
    func registerPitch(_ pitch: Double, neutral: Double) {
        guard state == .playing else { return }
        let offset = pitch - neutral

        if awaitingNeutral {
            // Wait for the phone to return roughly level before the next item.
            if abs(offset) <= neutralBand {
                awaitingNeutral = false
                advanceDeck()
            }
            return
        }

        if offset >= triggerDelta {
            // Tilt up = correct.
            markCurrent(correct: true)
        } else if offset <= -triggerDelta {
            // Tilt down = pass.
            markCurrent(correct: false)
        }
    }

    private func markCurrent(correct: Bool) {
        guard let item = currentItem else { return }
        if correct {
            guessed.append(item)
            flash = .correct
        } else {
            missed.append(item)
            flash = .pass
        }
        awaitingNeutral = true
    }

    private func advanceDeck() {
        flash = .none
        deckIndex += 1
        if deckIndex >= deck.count {
            endRound()   // got through the whole deck
            return
        }
        currentItem = deck[deckIndex]
    }

    private func endRound() {
        currentItem = nil
        flash = .none
        state = .recap
    }

    // MARK: Recap actions

    func playAgain() {
        guard currentCategory != nil else { return }
        // Re-enter readying so the player re-seats the phone and re-calibrates.
        resetRoundState()
        state = .readying
    }

    private func resetRoundState() {
        deck = []
        deckIndex = 0
        guessed = []
        missed = []
        timeRemaining = Self.roundDuration
        countdownValue = 3
        awaitingNeutral = false
        flash = .none
        currentItem = nil
    }
}
```

**Files:**

**Interfaces:**
- Consumes: `HeadsUpViewModel` (Task 3), `MotionTracker` (Task 2), `headsUpCategories` (Task 1). Mirrors existing game views' shape: `let onExit: () -> Void`.
- Produces: `struct HeadsUpView: View { let onExit: () -> Void }` — referenced by `ContentView` in Task 5.

**Design notes:**
- Owns a private `CADisplayLink` modifier — copy the TugOfWar pattern verbatim but rename the types to `HeadsUpDisplayLinkModifier` / `HeadsUpDisplayLinkView` to avoid symbol clashes (TugOfWar's are file-private, so names must still be unique per file; renaming is the safe choice).
- The display link callback computes `delta` from timestamps (same guard pattern as TugOfWar) and drives: countdown ticking, readying dwell detection, play-clock ticking, and per-frame `registerPitch`.
- Readying dwell: track how long pitch has stayed in the neutral band while landscape; when it exceeds `neutralDwell` (1.0s), call `beginCountdown()`. Capture `neutralPitch` at the moment the countdown finishes (transition into playing) — read it on the frame `startPlaying` happens. Simplest correct approach: capture `neutralPitch = motion.pitch` inside `beginCountdown`'s caller, i.e. when dwell completes, since the phone is by definition level then.
- Haptics: `UINotificationFeedbackGenerator` for correct (`.success`) / pass (`.warning`); `UIImpactFeedbackGenerator(style: .rigid)` for the final-seconds cue. Fire on `flash` changes via `.onChange`.
- Flash overlay: full-screen green/amber with big "CORRECT"/"PASS"; auto-clears because the model clears `flash` on deck advance, but also give it a `.animation` so it fades.
- Portrait prompt: when `state == .readying` and `!motion.isLandscape`, show "Turn sideways". During `.playing`, if `!motion.isLandscape`, overlay the same prompt but DO NOT pause (timer keeps running per spec).
- Item text is large and centered for the guessers to read.

struct HeadsUpView: View {
    @State private var viewModel = HeadsUpViewModel()
    @State private var motion = MotionTracker()
    let onExit: () -> Void

    @Environment(\.horizontalSizeClass) private var horizontalSizeClass
    private var isCompact: Bool { horizontalSizeClass == .compact }

    // Display-link timing.
    @State private var lastTimestamp: CFTimeInterval = 0
    // Readying dwell accumulator (seconds inside the neutral band, landscape).
    @State private var neutralDwell: Double = 0
    // Pitch captured as "level" when the countdown begins.
    @State private var neutralPitch: Double = 0

    private let neutralDwellTarget: Double = 1.0
    private let readyNeutralBand: Double = 15

    var body: some View {
        ZStack {
            switch viewModel.state {
            case .categoryPicker:
                categoryPicker
            case .readying:
                readyingView
            case .countdown:
                countdownView
            case .playing:
                playingView
            case .recap:
                recapView
            }

            flashOverlay
            topBar
        }
        .onAppear {
            motion.start()
            lastTimestamp = 0
        }
        .onDisappear {
            motion.stop()
        }
        .onChange(of: viewModel.flash) { _, newValue in
            fireHaptic(for: newValue)
        }
        .modifier(HeadsUpDisplayLinkModifier { timestamp in
            advance(to: timestamp)
        })
    }

    // MARK: - Tick driver

    private func advance(to timestamp: CFTimeInterval) {
        guard lastTimestamp != 0 else { lastTimestamp = timestamp; return }
        let delta = Double(timestamp - lastTimestamp)
        lastTimestamp = timestamp

        switch viewModel.state {
        case .readying:
            if motion.isLandscape && abs(motion.pitch) <= readyNeutralBand {
                neutralDwell += delta
                if neutralDwell >= neutralDwellTarget {
                    neutralPitch = motion.pitch
                    neutralDwell = 0
                    viewModel.beginCountdown()
                }
            } else {
                neutralDwell = 0
            }
        case .countdown:
            viewModel.tickCountdown(delta: delta)
        case .playing:
            viewModel.tickPlaying(delta: delta)
            viewModel.registerPitch(motion.pitch, neutral: neutralPitch)
        default:
            break
        }
    }

    // MARK: - Haptics

    private func fireHaptic(for flash: FlashKind) {
        switch flash {
        case .correct:
            UINotificationFeedbackGenerator().notificationOccurred(.success)
        case .pass:
            UINotificationFeedbackGenerator().notificationOccurred(.warning)
        case .none:
            break
        }
    }
}

private struct HeadsUpDisplayLinkModifier: ViewModifier {
    let onFrame: (CFTimeInterval) -> Void
    func body(content: Content) -> some View {
        content.background(HeadsUpDisplayLinkView(onFrame: onFrame))
    }
}

private struct HeadsUpDisplayLinkView: UIViewRepresentable {
    let onFrame: (CFTimeInterval) -> Void
    func makeUIView(context: Context) -> UIView {
        let view = UIView(frame: .zero)
        context.coordinator.start()
        return view
    }
    func updateUIView(_ uiView: UIView, context: Context) {
        context.coordinator.onFrame = onFrame
    }
    func makeCoordinator() -> Coordinator { Coordinator(onFrame: onFrame) }
    static func dismantleUIView(_ uiView: UIView, coordinator: Coordinator) {
        coordinator.stop()
    }
    final class Coordinator {
        var onFrame: (CFTimeInterval) -> Void
        private var link: CADisplayLink?
        init(onFrame: @escaping (CFTimeInterval) -> Void) { self.onFrame = onFrame }
        func start() {
            let link = CADisplayLink(target: self, selector: #selector(step(_:)))
            link.add(to: .main, forMode: .common)
            self.link = link
        }
        func stop() { link?.invalidate(); link = nil }
        @objc private func step(_ link: CADisplayLink) { onFrame(link.timestamp) }
    }
}
